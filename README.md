# Точка росы — офлайн-калькулятор (PWA)

Автономная утилита: температура + влажность → точка росы, влагосодержание воздуха
и проверка конденсата на поверхности. Никаких внешних зависимостей и запросов в сеть.

## Локальный запуск
Сам калькулятор работает даже с `file://`, но манифест и сервис-воркер — только через HTTP:
python3 -m http.server 8080 → http://localhost:8080

## Математика
Формула Магнуса, константы Alduchov–Eskridge (1996):
γ  = ln(RH/100) + 17.625·T / (243.04 + T)
Td = 243.04·γ / (17.625 − γ)

Погрешность ≈ ±0,4 °C при T = −40…+50 °C, RH = 1…100 %. Пределы ввода: T −60…+60 °C,
RH 0…100 %. При RH = 0 точка росы не определена («—»). Округление до 0,1
(половина — от нуля); целые значения при потере фокуса дополняются до «X,0».

Влагосодержание: `AH = 216.7·e/(273.15+T)` г/м³, где `e = RH/100 · 6.112·exp(17.625·T/(243.04+T))` гПа.

Вердикт по поверхности сравнивает округлённые значения: «сухо» (запас в °C),
«граница конденсации» (Δ = 0), «конденсат»/«иней» (поверхность ниже точки росы).
Расчёт над водой (как в метеоприложениях); ниже 0 °C точка инея над льдом физически
чуть выше — для бытовых задач разница несущественна.

## Приватность
Последние значения и тема хранятся только в `localStorage` устройства. Сетевых
запросов, аналитики и трекеров нет.
