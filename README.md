# 💧 Водичка

Минималистичный офлайн-трекер выпитой воды. Не напоминалка — просто
счётчик, который помогает не забывать о норме в течение дня.

Один HTML-файл, без зависимостей, без аккаунта, без рекламы, без аналитики.

## Возможности

- Счётчик мл и прогресс до дневной нормы
- Быстрые кнопки: 100 / 200 / 400 мл + произвольный объём
- Время и объем последней учтенной порции
- Норма по весу и возрасту (30 мл/кг с возрастной корректировкой)
- Неделя рядом: ✓ — норма, ◔ — частично, ○ — пусто
- Капля-маскот, которая радуется выполненной норме
- Работает офлайн после первого открытия (PWA)

## Приватность

Все данные хранятся только в localStorage вашего браузера.
Вес, возраст и история никуда не отправляются. Серверу нужен только
сам статический HTML при загрузке. Очистка данных сайта удаляет историю.

## Использование

Открыть ссылку → меню браузера → «Добавить на главный экран».
На Android напрямую открыть локальный file:// в Chrome не получится —
поэтому утилита раздаётся как статический сайт (GitHub Pages).

## Технологии

HTML + CSS + vanilla JavaScript, SVG-маскот, Service Worker.
Никаких фреймворков и сборщиков.
